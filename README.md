## 📌 Descrição do sistema
O **Vitallis** é um sistema de gestão terapêutica criado para centralizar informações clínicas, organizar atendimentos e otimizar o fluxo operacional de clínicas terapêuticas.

## 🎯 Objetivo do projeto
Oferecer uma plataforma prática e segura para apoiar a equipe clínica e administrativa no controle de pacientes, atendimentos, metas terapêuticas e indicadores de gestão.

## ✨ Funcionalidades principais
- 🔐 Autenticação de usuários
- 🛡️ Controle de permissões por perfil
- 👤 Cadastro e gestão de pacientes
- 📝 Registro de atendimentos terapêuticos
- 🎯 Gestão de metas terapêuticas
- 📊 Dashboard administrativo com visão operacional

## 🧰 Tecnologias utilizadas
- **HTML**
- **CSS**
- **JavaScript**
- **Firebase**
- **Git/GitHub**

## 🏗️ Arquitetura do projeto
O Vitallis é estruturado com base em:
- **MVC (Model-View-Controller)** para separação de responsabilidades
- **Engenharia de Requisitos** para levantamento e evolução orientada ao domínio clínico
- **MVP (Produto Mínimo Viável)** para entregas iterativas e validação contínua

## ▶️ Como executar o projeto
1. Clone o repositório:
   ```bash
   git clone https://github.com/JoabCoelh0/vitallis-system.git
   ```
2. Acesse a pasta:
   ```bash
   cd vitallis-system
   ```
3. Configure as credenciais do **Firebase** no arquivo de configuração do projeto.
4. Abra o `index.html` (ou execute com uma extensão de servidor local, como Live Server).
